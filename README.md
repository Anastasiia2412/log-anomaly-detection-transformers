# Application of Transformer Models for Log Anomaly Analysis and Forecasting

## General Information
**Student:** Обрезанова Анастасия Вадимовна
**Scientific Supervisor:** Саночкин Юрий

## Type of Work
This graduation qualification work is a project-oriented study focused on the development of a software solution
for log anomaly detection and forecasting using Transformer-based machine learning models.

## Objective
The objective of this work is to design and evaluate a software product for detecting and forecasting anomalies
in log data using Transformer models and to compare its effectiveness with baseline approaches.
